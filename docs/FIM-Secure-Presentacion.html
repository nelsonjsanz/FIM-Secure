S18 — Ciberseguridad
01 · Justificación Técnica

Motivo de Elección del Tema

Vector Principal de Ataque

El malware moderno modifica binarios del sistema para lograr persistencia silenciosa sin levantar sospechas.

Detección Tardía

Sin verificación criptográfica continua, la alteración de un archivo crítico se descubre semanas después del incidente.

Desafío Híbrido C / Python

Demostrar alto rendimiento en C combinado con gestión estructurada de datos e inmunidad OWASP en Python.

02 · Arquitectura de Software

Funcionamiento General

1

Motor C Nativo

  • ▸ Calcula hashes SHA-256 usando wincrypt.h
  • ▸ Bloques de 4 KB sin fugas de memoria
  • ▸ API nativa de Windows
2

Orquestador Python

  • ▸ Compara firma actual contra línea base
  • ▸ Consultas parametrizadas (Anti-SQLi)
  • ▸ Inmunidad OWASP
3

Base de Datos 3FN

  • ▸ SQLite con 4 tablas normalizadas
  • ▸ USUARIO, POLÍTICA, ARCHIVO, ALERTA
  • ▸ Registro permanente de incidentes

Esquema Relacional

USUARIO → POLÍTICA → ARCHIVO → ALERTA
